# Historical Documentation

This directory contains selected historical evidence and design context that
still has distinct provenance value. It is not a current implementation or
operating instruction source. Old RGBW terminology, legacy protocol layouts,
obsolete paths, and recorded test counts may appear in retained material and
must not override `CLAUDE.md`, `docs/CLOSED_LOOP_SPEC.md`, or current source and
tests. Duplicated guides, completed planning bundles, and software-only reports
may be removed when their useful contracts or decisions are represented in
current documentation and tests.
