# Current Documentation Index

This directory collects active operational runbooks, authoring guides, deployment manuals, maintenance procedures, and active investigation ledgers for the LIGHT-BELT system.
Presence in `docs/current/` indicates an active or retained operational role; it does not automatically make a document the authoritative specification for production hardware topology or technical contracts.
For canonical system facts and the current production topology, refer to [CLAUDE.md](../../CLAUDE.md), [CLOSED_LOOP_SPEC.md](../CLOSED_LOOP_SPEC.md), and [config/profiles/rk3588-host-service.yaml](../../config/profiles/rk3588-host-service.yaml).
Show authors should start from [show-authoring-source-index.md](show-authoring-source-index.md), while deployment and maintenance engineers should consult the corresponding operational guides below.
