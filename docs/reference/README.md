# Technical Reference & API Contracts Index

This directory collects technical specifications, API contracts, internal authoring models, wire protocols, and research inventories for the LIGHT-BELT system.
`docs/reference/` contains both:
1. normative, active technical contracts (such as the frozen external Host API V1 and internal authoring specifications);
2. supporting technical references, research inventories, closed studies, and historical provenance records.

Specific document authority must be determined by each entry's **Type**, **Status**, and **Authority / evidence role** in the table below. The external control APP interface is strictly defined by Host API V1 ([host-api-v1.md](host-api-v1.md) and [host-api-v1.openapi.yaml](host-api-v1.openapi.yaml)), while advanced authoring capabilities ([effect-parameter-metadata.md](effect-parameter-metadata.md), [parameter-modulation.md](parameter-modulation.md), [color-source.md](color-source.md)) are internal engine specifications encapsulated within Show YAML.
