# 安装、维护与开发工具脚本

| 子目录 | 用途 |
|---|---|
| `acceptance/` | 软件验收、测试节目生成与摘要检查 |
| `agents/` | 自动协作任务、执行记录及工作树管理 |
| `benchmarks/` | 软件性能测量，不代替 RK3588 实机测量 |
| `deploy/rk3588/` | RK3588 设备安装、显示会话和服务集成 |
| `dev/` | Windows 开发环境准备与灯光编排约定导出 |
| `hardware/` | 显式硬件检查、状态读取与诊断轨迹回放 |
| `maintenance/` | 设备数据备份和锁定版本更新 |
| `runtime/` | 运行配置生成、节点解析与网络设置 |
| `compliance/` | 依赖与许可材料采集工具 |
| `archive/` | 保留的历史工具，不作为当前操作入口 |

根目录几个短 shell 文件是旧路径的兼容入口，真正实现位于相应子目录。安装、更新和硬件工具会改变设备状态，应按对应说明使用；不要把归档的一次性迁移脚本当作日常清理工具。
