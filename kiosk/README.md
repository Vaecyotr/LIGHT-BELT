# 网页控制界面

这里存放节目选择、播放控制、亮度与音量调节等操作页面。`kiosk` 是原有技术名称，保留路径以维持构建和部署引用。

- `src/`：页面与接口调用源码；`App.vue` 为主要操作页面。
- `public/`：构建时原样复制的文件，包括第三方许可声明。
- `dist/`：主机实际提供给浏览器的已构建页面、JS、CSS 和声明文件；当前发布包需完整保留。
- `package.json`、`package-lock.json`：网页依赖声明与锁定版本；使用 `npm ci` 安装，`npm run build` 构建。

网页通过主机接口控制节目；灯光算法和设备接线配置不在本目录。修改界面后必须同时核对构建产物及其引用，不能只验证接口健康检查。设备桌面全屏会话设置位于部署脚本中，与本网页源码职责不同。
