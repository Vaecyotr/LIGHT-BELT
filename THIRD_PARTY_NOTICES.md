# LIGHT-BELT third-party notices — distribution preparation

Status: **BLOCKED / NOT A RELEASE CLEARANCE**. Audit date: 2026-10-26.

This index and the accompanying original license texts apply to the identified third-party components. They do not license LIGHT-BELT's independently owned application source under an open-source license. Ownership and customer license terms for that source still require confirmation by the sales entity. The existing README statement `proprietary, internal use` is not a customer product license.

The local evidence package is [the generated inventory and notices](docs/compliance/generated/THIRD_PARTY_NOTICES.md). It includes all uv lock variants, npm lock entries and installed Windows package notices; it is **not** the bill of materials of the final ARM system image. Package metadata is a discovery aid, not a substitute for the original license files or corresponding source.
